# Calculator App

A simple, interactive calculator web application built with HTML, CSS, and JavaScript.

## Features

- ✨ Basic arithmetic operations (addition, subtraction, multiplication, division)
- 🎨 Clean and modern UI with gradient background
- 📱 Fully responsive design (works on mobile, tablet, and desktop)
- ⌨️ Easy-to-use button interface
- ✖️ Error handling for invalid expressions

## Live Demo

Access the live calculator here: https://cyber-sentinel6313.github.io/Calculator-/

## How to Use

1. Click on number buttons to enter values
2. Click on operation buttons (+, -, *, /) to perform calculations
3. Click the "=" button to get the result
4. Click "C" to clear the display
5. Click "←" to delete the last character

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Calculator logic

## Installation

No installation needed! Just open `index.html` in your browser or access the live demo link.
